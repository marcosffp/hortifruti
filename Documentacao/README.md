# Documentação do Projeto - Hortifruti SL

Este diretório contém a documentação formal do projeto de desenvolvimento do sistema de gestão para o Hortifruti Santa Luzia LTDA.

## Conteúdo

### Hortifruti SL - Documentação.pdf

Relatório técnico completo do projeto, estruturado nos seguintes capítulos:

#### Capítulo 1 - Introdução
- Contextualização do problema enfrentado pelo Hortifruti Santa Luzia LTDA
- Processos manuais críticos: conciliação bancária e agrupamento de vendas por cliente
- Objetivos gerais e específicos do sistema
- Justificativa para o desenvolvimento da solução

#### Capítulo 2 - Fundamentação Teórica
- Conceitos de sistemas de gestão empresarial
- Tecnologias utilizadas: Java Spring Boot, Next.js, TypeScript
- Integração com APIs externas (Sicoob, Google Maps, SendGrid)

#### Capítulo 3 - Materiais e Métodos
- Metodologia ágil Scrum aplicada ao projeto
- Ferramentas de desenvolvimento: VS Code, IntelliJ, Git/GitHub
- Arquitetura do sistema (Backend REST + Frontend SPA)
- Banco de dados MySQL e modelagem de dados
- Requisitos funcionais (RF001-RF030) e não funcionais

#### Capítulo 4 - Resultados
- Funcionalidades implementadas por sprint
- Telas e interfaces desenvolvidas
- Integração com sistemas externos (boletos, notificações, NF-e)
- Avaliação pelos usuários via questionário

#### Capítulo 5 - Conclusão
- Análise dos objetivos alcançados
- Contribuições do projeto para o cliente
- Sugestões para trabalhos futuros

#### Referências Bibliográficas
- Documentação técnica das tecnologias utilizadas
- Artigos e materiais de apoio

## Elaboração

Documentação elaborada no Overleaf durante as Sprints 1 a 5, com revisão final na Sprint 5 para entrega do projeto.
